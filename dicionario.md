# DICIONÁRIO DE DADOS DA BASE

# tabela VENDAS

* id_venda - Identificador único da venda
* data_venda - Data em que a venda ocorreu
* cliente - Nome do cliente
* produto - Nome do produto vendido
* categoria - Categoria do produto
* quantidade - Quantidade vendida
* preco_unitario - Preço unitário do produto
* vendedor - Nome do vendedor
* cidade - Cidade da venda
* estado - Estado da venda


# tabela RESUMO_VENDAS

* produto - Nome do produto vendido
* categoria - Categoria do produto
* quantidade_total - Soma das quantidades de cada produto vendido
* faturamento_total - Faturamento baseado na quantidade vendida e no preço unitário de cada produto
